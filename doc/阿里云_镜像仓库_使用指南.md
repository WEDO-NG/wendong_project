## 3. 进阶：使用阿里云镜像仓库 (解决服务器内存不足问题)

对于 2核2G 的服务器，直接在服务器上构建 (docker build) 经常会导致内存溢出。推荐使用 **“本地构建 -> 推送镜像仓库 -> 服务器拉取”** 的流程。

### 3.1 开通阿里云容器镜像服务 (ACR)

1.  登录 [阿里云容器镜像服务控制台](https://cr.console.aliyun.com/)。
2.  点击左侧 **“实例列表”**，选择 **“创建个人版实例”** (免费)。
    - 实例名称建议：`wendong-registry`
3.  点击创建好的实例，设置 **“访问凭证”** (设置一个固定的 Docker 登录密码)。
4.  创建 **命名空间**：
    - 点击左侧 **“命名空间”** -> **“创建命名空间”**。
    - 名称建议：`wendong-space` (设置为私有)。
5.  创建 **镜像仓库** (我们需要创建两个)：
    - 仓库1：`server-node` (代码源选择“本地仓库”)
    - 仓库2：`web-react` (代码源选择“本地仓库”)

### 3.2 本地构建与推送 (在你的 Mac/PC 上操作)

为了简化操作，项目中已提供脚本 `scripts/build-prod.sh`。

1.  **修改脚本配置**：打开 `scripts/build-prod.sh`，将 `REGISTRY_URL` 和 `NAMESPACE` 修改为你刚才创建的地址。
    - 例如：`registry.cn-hangzhou.aliyuncs.com/wendong-space`
2.  **运行脚本**：

    ```bash
    # 赋予执行权限
    chmod +x scripts/build-prod.sh

    # 运行构建并推送
    ./scripts/build-prod.sh
    ```

    _(脚本会提示你输入阿里云 Docker 密码)_

### 3.3 服务器拉取与运行 (在 ECS 上操作)

1.  **登录镜像仓库**：
    ```bash
    docker login --username=<你的阿里云账号> registry.cn-hangzhou.aliyuncs.com
    ```
2.  **启动服务**：
    修改 `docker-compose.prod.yml` 使用镜像地址后 (见下文)，执行：
    ```bash
    docker compose -f docker-compose.prod.yml up -d
    ```
